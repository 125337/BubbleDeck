# BubbleDeck 插件端 · 收费闸门接入方案

> 2026-11-03。对接已上线的授权 API（`https://qb.xhhan.xyz/bd/*`），契约见 [授权系统方案.md](授权系统方案.md)。

## 总览

```
微信启动 → dylib 加载
  ├─ Keychain 有 token → verify 报到
  │     ├─ code 0        → 已激活，气泡引擎正常工作
  │     ├─ 2001/过期     → 用 Keychain 里的卡密自动重新 activate（无感）
  │     └─ 网络失败      → 7 天兜底期内继续用，超期视为未激活
  └─ 无 token → 未激活，hook 全部放行官方图（插件可装可用，仅无内容）
```

## 新增文件（4 个，~600 行）

| 文件 | 职责 |
|---|---|
| `Core/TDNet.h/.m` | 网络层：POST 四接口、`X-BD-Ts`+`X-BD-Sign`（HMAC-SHA256, CommonCrypto，SALT 内置）、同步封装（hook 后不能异步等结果，启动报到用异步即可） |
| `Core/TDLicense.h/.m` | 授权状态机：Keychain 存 token/card/device_id；`activate:`、`verify`、`state`（未激活/有效/兜底过期）；启动时自愈逻辑 |
| `Engine/TDZip.h/.m` | 解压器：.bdpack 剥头（BDPK4+版本1+IV16）→ CommonCrypto AES-256-CBC 解密 → zip 解析落盘。zip 解析器从 ThemeDeck v1 git 历史捞回（纯 libz，零第三方依赖，BubbleDeck 已链 -lz） |
| `Entry/TDOnlinePage`（并入 TDBubbleEntry） | UI：激活卡 + 在线包列表 + 下载进度 |

## 设置页 UI 变更（在现有页面之上加两个区）

```
┌ 激活状态卡 ────────────────┐
│ 未激活：[输入卡密激活] 按钮      │
│ 已激活：✓ 已激活 · 设备码后4位   │
└────────────────────────┘
（现有：本地包列表卡片，不变）
┌ 在线包区 ─────────────────┐
│ 蜜糖邦尼气泡包 v1.0  [下载]   │
│ 下载中 45% → 校验 md5 → 解密  │
│ → 解压落 packs/ → 出现在本地列表│
└────────────────────────┘
```

- 激活流程：弹窗输入卡密 → `/activate`（自动带 IDFV+wxid+系统信息）→ 成功存 Keychain → 页面刷新
- **激活成功后自动引导下载**：刷新后自动拉 `/packs` 列表并高亮第一个包的[下载]按钮（买卡→看见新气泡 = 填码+点下载两次点击）
- 错误码转人话：1001 卡不存在 / 1002 已停用 / 1003 设备数超限(换机提示) / 4003 网络异常
- 在线包列表 `/packs`（不含 key）；下载 `/download` 取 url+md5+key → 下载 → md5 校验 → 解密解压 → `Documents/BubbleDeck/packs/<包名>/`

## 收费闸门（TDBubbleEngine 改动，~20 行）

```objc
// imageNamed hook 入口处（现有 miss 放行逻辑之前）：
if (TDLicenseState != Active) return %orig;   // 未激活/过期 → 全部官方图
// 其余逻辑不变
```

状态在启动时算好存内存，hook 路径零开销（一个 BOOL 判断）。

## 安全妥协（明说）

- SALT 与 API 地址硬编码在 dylib：dump 出来可伪造请求签名，但伪造不了有效卡密（卡在服务器库里）
- patch 掉闸门判断 = 破解，V1 接受（服务器 verify 只保证"真客户端"的实时封卡能力）
- 卡密明文存 Keychain（自动重激活需要），越狱可提取——提取者也只多占一台设备名额（服务器 1003 拦着）

## 实施顺序

1. TDNet + TDLicense（纯逻辑，可先用线上 API + 真卡密在本地 Mac/模拟器逻辑测？→ 不行，dylib 只能真机；直接进 CI 构建后真机测）
2. TDZip 解密解压（用 `test_out.bdpack` 真实产物做单测素材——把它打进 bundle 或临时放 Documents）
3. 激活卡 + 在线包 UI
4. 闸门接入 + 全流程真机验收：未激活全官方图 → 激活 → 下载包 → 气泡生效 → 后台封卡 → 重启微信气泡消失

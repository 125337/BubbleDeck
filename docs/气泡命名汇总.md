# 气泡命名汇总（canonical 清单）

微信聊天页气泡 PNG 走 `-[MMThemeManager imageNamed:]` / `imageNamed:warnIfNotFound:` 取图，请求名 `ChatRoom_Bubble_*`。BubbleDeck 只接该前缀，其余请求一律放行原图。

亮暗配对规则：暗屏时请求 `X` → 包内优先取 `X_Dark`，没有自动回落 `X`。

来源：蜜糖邦尼主题（`convert_legacy` 转制），微信 8.0.54+。

## 二、架构总览

```
客户端 dylib（iOS tweak，注入微信）          服务器（/opt/BubbleDeck_server/）
  TDNet ──HTTPS──> /bd/activate 激活（卡号+wxid）    app.py   授权 API + 限频
  TDLicense（现取形态：清单+key 仅内存）──> /bd/packs    admin.py  管理后台 /admin
  TDContainer（BDP2 GCM 解密+zip 索引+按条目取图）     biz.py    商家门户 /biz
  TDBubbleEngine（取图 hook，闸门 gateOpenForPack）    session.py 后台会话（双 secret）
  商店页下载 .bdpack → 零解压装进沙盒（盘上常密）        manage.py 发卡/登记 CLI
                                                      bd.db + licenses/*.json
打包工具 tools/pack.py（BDP2 唯一实现，禁止别处另写加密）
```

## 三、V4 核心设计（本轮重构，必须懂的几点）

1. **客户端零秘密**：dylib 无 SALT、无签名头、无 key 落盘。被逆向只得到空壳。
2. **key 现取现用**：清单（含包密钥）每次启动/进商店页/激活后现取（POST /packs），仅进程内存持有；Keychain 旧字段（entitlements/lastSync）启动自动清理。断网=会话内沿用内存，重启后必须联网。
3. **后台会话与客户端彻底脱钩**：session.py 用 `BD_ADMIN_SECRET`/`BD_BIZ_SECRET` 环境变量 scope 混签，cookie 跨域无效。SALT 已从 app.py/admin.py/biz.py 全部删除。
4. **限频**（按 device_id|IP，实例内存滑动窗）：activate 100 次/时→1007；packs 120 次/时→429。原则：限频是减速带，数字按真实用量 10 倍冗余，绝不误伤买家。
5. **封卡三态 UI**（本轮新增）：/packs 响应带 `revoked` 名单；主题页显示全部本地已装在线包，四态角标——正常 / 已封禁（revoked）/ 未授权（换微信号）/ 待验证（断网未报到）；点击拦截文案按状态区分；左滑删除四态可用；取图热路径 gateOpenForPack 闸门不变（双保险）。
6. **信任共识**：key 按包共发（同包买家一把 key），买家自泄 key = 模式天花板，技术不可解；wxid 声称≈买家自泄，无增量危害。不做水印溯源。事件响应 = 封卡（即时生效）+ 换 key 重签（tools/pack.py repack_version）。

## 五、规矩与坑（血泪，必读）

1. **构建必须前台阻塞等待产物落地**（用户规矩，build.py all 会等到 CI 完成并下载 dylib）
2. **AAD 一致性铁律**：info.json 的 name/version 必须与加密时 AAD 完全一致，后台上传强制重写 info.json
3. **keys 表是唯一 key 来源**（packs.packkey 是遗留摆设）；真实库路径 `/opt/BubbleDeck_server/server/bd.db`（**大写 B**，sqlite3.connect 会静默新建空库，路径敲错不报错但写进空库）
4. 后台所有接口只收 **multipart/form-data**（formdict 历史事故，原生表单必须写 enctype）
5. PowerShell 5 不支持 `&&`（用 `;`）；Windows 传中文参数有 GBK 坑，路径在 python 内部构造
6. CCCryptorGCMOneshotDecrypt 私有 SPI 在 iOS 13 前后 ABI 不同——已彻底自实现 GCM，不要回头用 SPI
7. GHASH 必须查表加速（逐位乘法会让主题页卡死 1-4 秒）
8. 中文校验二进制时注意：NSString 字面量以 **UTF-16** 存在 dylib 里，按 UTF-8 搜会漏报

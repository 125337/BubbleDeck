## 业务模型（后端实现依据，已定稿）

- 卡**永久**有效；1 卡 = 1 设备；换绑不做（换机=重新发卡）
- 客户端每次启动 verify 报到 → 封卡（revoke）即下次报到失效
- 本地凭证 7 天兜底；过期后客户端自动重新激活
- 请求头：`X-BD-Ts`（毫秒时间戳）+ `X-BD-Sign = HMAC-SHA256(SALT, "{ts}|{body}")`，±300s
- 包文件放 GitHub Releases 公开直链（哑管道），32 字符 key 只在 /download 验 token 后下发

## 部署更新方式

改了 `server/` 代码后：宝塔文件管理器覆盖上传对应文件 → `systemctl restart bdapi`。数据库 `bd.db` 在服务器上，勿覆盖。

## 坑

- PowerShell 5 不支持 `&&`（用 `;`）；Windows 命令行传中文参数有 GBK 转码坑，路径含中文一律在 python 内部构造
- 服务器宝塔 Nginx 已占 80/443，API 只走反代不抢端口
